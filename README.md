# 闪乱神乐 少女们的证明（SENRAN KAGURA SHINOVI VERSUS）Steam 版 · 简体中文汉化补丁 v1.8

以日文为底本的简体中文汉化。中文替换的是游戏的**英语**语言槽，所以游戏内语言请选「English / 英语」。

## 汉化内容
- **文本**：全部菜单与系统文字、剧情模式全部剧情（含幕间、终章、街机剧情）、教程、街机模式角色对话、角色语音字幕。
- **字库**：中文字库，与英文字母基线对齐。
- **界面美术字**：
  - 汉字能看懂的，直接用官方日文版原图；
  - 英日两版都是英文的，保留英文原图；
  - 其余（含假名或看不懂的）重绘为中文，例如标题画面、道场、训练所、任务、记录、购买部、能力页。
- **2D 界面模型**：能力页和任务页标题的拼接位置做了微调，以适配中文排版。

## 安装
1. 下载本仓库（Code → Download ZIP），解压后把整个文件夹放进游戏目录，和 `SKShinoviVersus.exe` 同一层或更深都可以。
2. 双击 `install.bat`。
   - 安装前会逐个核对游戏文件是否为原版。只要有一个不是，就一个字节都不写，并提示原因。
   - 写入后会逐个回读核对，出错自动回滚。
   - 原版文件备份在 `游戏目录\_汉化补丁备份\1.8\`。
3. 推荐安装 PowerShell 7（pwsh）。没有的话会自动改用 Windows 自带的 PowerShell。

## 卸载 / 查看状态
- **卸载**：双击 `uninstall.bat`，从备份还原，并核对与原版逐字节一致。如果备份丢失，也可以用 Steam「验证游戏文件完整性」恢复原版。
- **查看状态**：双击 `status.bat`，可以看到每个文件当前是 原版 / 已打补丁 / 未知。

## 注意
- 适用于 Steam 现行版。补丁只改数据文件，不改游戏主程序。
- 装过其他汉化补丁（例如旧版 ALI213 补丁）的，请先卸载它，或用 Steam 验证游戏文件后再安装。
- 游戏更新后，如果安装器提示文件不是原版，说明游戏文件变了，需要等补丁更新。
